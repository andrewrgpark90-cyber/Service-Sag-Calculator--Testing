Calculation note

Cable profile uses a parabolic approximation: straight-line height between attachments minus 4 × maximum sag × x × (span − x) / span². Ground is drawn as a straight grade between network ground and the entered property FFL. Sag values are sourced from the workbook's lookup table, with linear interpolation for intermediate spans. The lowest absolute point of the cable can be offset from midspan when pole heights differ. This is an indicative visualisation, not an approved Energex clearance calculation; confirm the sag reference and ground profile before field use.
